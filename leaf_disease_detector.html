Plant Leaf Disease Detection using CNN

Deep neural network mini project: MobileNetV2 transfer learning running in your browser.

Loading the MobileNet model. This takes a few seconds...

Step 1: Teach the model

Add a class for each leaf condition, then upload several example photos for each. Use at least 5 photos per class for good results (PlantVillage images work well).

Step 2: Test a new leaf

Upload a leaf photo the model has not seen. It predicts the closest class and shows its confidence.

The prediction will appear here.

About this project

  • Model: MobileNetV2 pretrained on ImageNet (feature extractor).
  • Classifier: K-Nearest Neighbours on the 1280-value feature vectors (k = 3).
  • Technique: Transfer learning, so very little data and no long training is needed.
  • Libraries: TensorFlow.js, MobileNet model, KNN classifier.
  • Note: Everything runs locally. Your images are never uploaded anywhere.
